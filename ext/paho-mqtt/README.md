# Gebündeltes paho-mqtt

Dies ist eine unveränderte Kopie von [paho-mqtt](https://github.com/eclipse/paho.mqtt.python)
(Version 2.1.0), damit `dbus-openwb2` ohne Netzwerk/pip installierbar ist.

Der Treiber und das Web-Interface nutzen zuerst ein systemweit installiertes
paho-mqtt und fallen nur auf diese Kopie zurück, wenn keines vorhanden ist.
